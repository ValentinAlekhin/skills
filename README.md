# Личные скиллы

Набор личных скиллов для разработки. Каждый скилл хранится в отдельной папке
с инструкциями в `SKILL.md`.

| Скилл | Назначение |
| --- | --- |
| [mvp](mvp/SKILL.md) | Создание веб-MVP: Nuxt, Strapi при необходимости CMS, общий код в `common/` и Docker для всех сервисов. |

Примеры запросов после подключения скилла:

```text
$mvp Создай MVP каталога с редактированием контента через CMS.
$mvp Сделай лендинг с формой заявки без CMS.
```
